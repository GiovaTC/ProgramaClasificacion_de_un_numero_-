programa básico de consola en Java 21 + IntelliJ IDEA + Oracle 19c, utilizando 3 condicionales y guardando el resultado en Oracle.

Programa: Clasificación de un número

El usuario ingresa un número y el programa utiliza tres condicionales:

Determina si el número es positivo.
Determina si es negativo.
Determina si es cero.

Además, cada ejecución se almacena en Oracle 19c.

Conexión a Oracle

Por ejemplo:

package config;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class ConexionBD {

    private static final String URL =
            "jdbc:oracle:thin:@localhost:1521/orcl";

    private static final String USUARIO = "system";
    private static final String PASSWORD = "oracle";

    public static Connection conectar() throws SQLException {
        return DriverManager.getConnection(
                URL,
                USUARIO,
                PASSWORD
        );
    }
}

Si tu usuario o contraseña de Oracle 19c son diferentes, simplemente se modifican esos valores.

DAO para guardar la información
package dao;

import config.ConexionBD;

import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.SQLException;

public class NumeroDAO {

    public void guardar(int numero, String clasificacion) {

        String sql = """
                INSERT INTO numeros (numero, clasificacion)
                VALUES (?, ?)
                """;

        try (Connection connection = ConexionBD.conectar();
             PreparedStatement statement =
                     connection.prepareStatement(sql)) {

            statement.setInt(1, numero);
            statement.setString(2, clasificacion);

            statement.executeUpdate();

            System.out.println("Información guardada en Oracle 19c.");

        } catch (SQLException e) {
            System.out.println(
                    "Error al guardar en Oracle: " + e.getMessage()
            );
        }
    }
}

Programa de consola
import dao.NumeroDAO;

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner scanner = new Scanner(System.in);
        NumeroDAO numeroDAO = new NumeroDAO();

        System.out.println("==============================");
        System.out.println("  CLASIFICADOR DE NUMEROS");
        System.out.println("  Java + Oracle 19c");
        System.out.println("==============================");

        System.out.print("Ingrese un número: ");
        int numero = scanner.nextInt();

        String clasificacion = "";

        // Condicional 1
        if (numero > 0) {
            clasificacion = "POSITIVO";
        }

        // Condicional 2
        if (numero < 0) {
            clasificacion = "NEGATIVO";
        }

        // Condicional 3
        if (numero == 0) {
            clasificacion = "CERO";
        }

        System.out.println();
        System.out.println("Número: " + numero);
        System.out.println("Clasificación: " + clasificacion);

        numeroDAO.guardar(numero, clasificacion);

        scanner.close();
    }
}
